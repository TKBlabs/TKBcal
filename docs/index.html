概要

// overview

TKBcalは、月めくり操作を減らして中長期の見通しを立てるための年間カレンダーです。 画面幅に応じたスケール調整で、1画面に複数か月を読みやすく表示します。

祝日データはオンラインAPIから取得し、ユーザー定義の休日も追加・削除可能。 今日の日付・当月の強調表示とツールチップで、年間表示でも現在地を見失いにくくしています。

会計年度ベース15か月表示

4〜9月は前年度1〜3月、10〜3月は翌年度4〜6月を補完し、年間前後の流れまで確認できます。

祝

祝日APIの自動取得

holidays-jp APIから祝日データを読み込み、年度をまたぐ祝日確認をすばやく行えます。

＋

ユーザー休日の登録

平日をダブルクリックして休日名を付けると、緑字で表示。社内休業日や独自の記念日の管理に使えます。削除もできます。

●

今日と当月の強調表示

当月枠をハイライトし、当日は背景色と枠線で表示。年間表示でも現在日を追いやすくします。

日付ツールチップ

祝日や今日の日付にマウスを乗せると、日付・曜日・祝日名・「今日」をポップアップで表示します。

# TKBcal

1年分のカレンダーを1画面で見渡せる、macOS用の年間カレンダーアプリです。

## インストール

  • DMGを開き、TKBcal.app を「アプリケーション」フォルダへドラッグします
  • Appleの公証（Notarization）済みのため、そのままダブルクリックで起動できます
  • 祝日の取得にはインターネット接続が必要です

## アップデート

  • 24時間ごとに自動で更新を確認し、新しい版があればお知らせします
  • メニュー「TKBcal」→「アップデートを確認...」から手動でも確認できます
  • 自動確認の有無は 設定（⌘,）→ 更新 で切り替えられます

## 動作環境

  • macOS Tahoe 26.5以降
  • Apple Silicon 搭載Mac（Intel Mac非対応）

## 主な機能

  • 会計年度（4月始まり）を軸にした15か月の年間表示と、現在日時の表示
  • 日本の祝日の自動取得と、平日のダブルクリックでのユーザー休日の登録
  • 月の表示（日本語／英語／日本語＋英語）と和暦表示の切り替え（設定 → 一般）
