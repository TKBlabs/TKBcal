# TKBcal

macOS用の年間表示カレンダーアプリです。会計年度（4月始まり）を軸に15か月分を1画面に並べ、日本の祝日を自動で反映します。会社の休業日や記念日などを「ユーザー休日」として登録することもできます。

- **ダウンロード**: [Releases](https://github.com/TKBlabs/TKBcal/releases)（最新版のDMG）
- **製品ページ**: https://apps.tkbtk.com/TKBcal/
- **動作環境**: macOS 26.5以降、Apple Silicon（Intel Macには対応していません）
- **ライセンス**: フリーウェア（個人・商用を問わず無料）

## インストール

1. [Releases](https://github.com/TKBlabs/TKBcal/releases)から最新版の `TKBcal_<バージョン>.dmg` をダウンロードします。
2. DMGを開き、`TKBcal.app` を「アプリケーション」フォルダへドラッグします。
3. 「アプリケーション」フォルダから起動します。

アプリとDMGはどちらもAppleの公証（Notarization）を受けています。初回起動時に「インターネットからダウンロードされたアプリケーションです」と確認が出たら「開く」を押してください。

> [!IMPORTANT]
> DMGの中やダウンロードフォルダから直接起動すると、自動アップデートがうまく動かないことがあります。必ず「アプリケーション」フォルダへ移してから起動してください。

## アップデート

自動アップデート（Sparkle）に対応しています。

- 24時間ごとに新しい版を確認します（設定の「更新」でオン・オフできます）。
- メニュー「TKBcal」→「アップデートを確認...」、または設定の「更新」の「今すぐ確認」で、すぐに確認することもできます。

各版の変更点は[Releases](https://github.com/TKBlabs/TKBcal/releases)に載っています。

## 主な機能

### 15か月の年間表示

カレンダーは3段×5列で、1列に3か月ずつ並びます。今が上期か下期かで、表示する範囲が変わります。

| 今の月 | 表示する範囲 |
| --- | --- |
| 4〜9月 | 今年の1〜3月（前年度の終わり）＋ 今年度の4月〜翌年3月 |
| 10〜3月 | 今年度の4月〜翌年3月 ＋ 翌年度の4〜6月 |

- 画面上部に現在の日時（`2026/11/18(水) 10:30:00` の形）を1秒ごとに表示します。
- 今月は黄色の枠で、今日は黄色の背景とオレンジの枠で強調します。日付が変わると自動で切り替わります。
- 日曜と祝日は赤、土曜は青、ユーザー休日は緑の文字で表示します。
- ウィンドウの幅に合わせて、文字とマスの大きさが拡大・縮小します。縦に収まらないときはスクロールできます。

### 祝日

日本の祝日を、起動時に [holidays-jp API](https://holidays-jp.github.io/) から取得します（インターネット接続が必要です）。祝日や今日の日付にマウスを乗せると、日付・曜日・祝日名・「今日」をポップアップで表示します。

### ユーザー休日

1. 平日の日付を **ダブルクリック** します（土日と祝日は登録できません）。
2. 休日の名前を入力して「保存」（またはEnterキー）を押します。

登録した日は緑の文字になり、マウスを乗せると名前が出ます。もう一度ダブルクリックすると、名前の変更や「削除」ができます。登録した内容はこのMacに保存され、アップデートしても残ります。

## 主なショートカット

| キー | 内容 |
| --- | --- |
| ⌘, | 設定を開く |
| ⌘N | 新しいウィンドウを開く |
| ⌘W | ウィンドウを閉じる |
| ⌘Q | TKBcalを終了 |

## 設定（⌘,）

| タブ | 項目 | 内容 |
| --- | --- | --- |
| 一般 | 月の表示 | 「日本語（1月）」「英語（Jan）」「日本語＋英語（1月 Jan）」から選びます |
| 一般 | 和暦を表示 | オンにすると、左上に「令和8年」のように和暦を表示します |
| 更新 | アップデートを自動的に確認 | 24時間ごとの自動確認のオン・オフ |
| 更新 | 最終確認・今すぐ確認 | 最後に確認した日時の表示と、手動での確認 |
| 更新 | このバージョン | 今のバージョンとビルド番号 |

## 困ったときは

- **祝日が表示されない**: 祝日は起動時にインターネットから取得します。接続を確かめて、TKBcalを起動し直してください。
- **日付をダブルクリックしても入力欄が出ない**: 土日と祝日にはユーザー休日を登録できません。
- **アップデートがうまくいかない**: TKBcalを「アプリケーション」フォルダへ移してから起動し直し、「アップデートを確認...」を試してください。うまくいかなければ、[Releases](https://github.com/TKBlabs/TKBcal/releases)から最新版のDMGをダウンロードして入れ直してください（ユーザー休日は残ります）。

## プライバシー

TKBcalが外部と通信するのは、次の2つだけです。

- 祝日データの取得（`holidays-jp.github.io`）
- アップデートの確認（`apps.tkbtk.com` と、更新ファイルのダウンロード先の `github.com`）

ユーザー休日と設定はこのMacの中だけに保存し、外部へは送りません。
